Recent progress and upcoming releases

A summary of updates, standalone version packs, and the upcoming Exride 4.0.0 release.

In recent days, we have been testing new methods to roll out natively meaningful updates within the Exride tool. We’ve launched the forums page on the official site, and introduced new templates featuring very high-fidelity graphics with lighting pre-adjusted so creators can experiment with visuals right away. We’ve also improved the application’s optimization. Going forward, the store page will only be available inside the application and will no longer be hosted as a public web page.

Standalone versions

We’ve added standalone version packs. Standalone versions are packages you must install before creating a new project; they provide the assets used by templates. These packs will include free asset packs and many open-source files for experiences and more. The packs are generation-based, meaning they are produced according to generation tiers rather than being hand-made individually.

Examples:
  • ExrideGen 1.0.0 — Includes map files with low graphics and a small selection of maps.
  • ExrideGen 1.5.0 — Includes map files with improved graphics, much larger maps, and more advanced features.
  • ExrideGen 2.0.0 — Includes 4K map files, high-detail graphics, extremely large maps, and enhanced graphics technology provided by Exride. This pack also enables automatic graphics improvements each time you create a project and includes advanced enhancements.

These new features are scheduled to arrive at the end of September, alongside additional site optimization improvements.

Exride 4.0.0 will also be released as a major update featuring a brand-new UI built from the ground up, improved animations, a cleaner and more modern visual style, and further application optimizations. Available: September 15, 2025.
